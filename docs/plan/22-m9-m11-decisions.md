## 22. M9 and M11 decisions

These defaults resolve ambiguities found while planning Android insertion (M9)
and the Android assistant (M11), the same way §§20–21 record owner-overridable
defaults. The plan proceeds on them unless the owner says otherwise. Each
row names the slices it gates (N = M9 Android delivery, L = M11 assistant);
a slice that changes a contract amends the referenced section in the same PR.
