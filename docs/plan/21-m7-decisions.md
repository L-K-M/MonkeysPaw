### Owner decisions with defaults

- **Repeat privacy:** exact session fields, remember-fields only on disk;
  session-only deliveries cannot silently repeat after restart. Refresh builtins
  and review changed sources; amend §5/§6/§12 (G3/G4).
- **Restore guarantee:** off, previous text only, 750 ms and revision/ownership
  guards. Accept the disclosed simultaneous-copy OS limit or leave restore
  unavailable where absolute protection is required (G13/G14).
- **Terminal aliases:** use G11's eight proposed aliases only with real
  WM_CLASS/chord evidence. No guessed XTerm support or confirmation modal;
  Standard default and explicit Terminal remain on Wayland/Flatpak (G11/G12).
- **Flatpak access/distribution:** GNOME Platform/SDK 50, x86_64 deb repack,
  disclosed home access, no dconf/host escape, precise optional tray permission.
  GitHub bundle/checksum with explicit reinstall/update steps; Flathub supplies
  runtime only. Export merged E28 URI handling (G18–G22).
- **Updates/reporting/hardware:** retain Q11 on/daily/stable with browser-only
  release action. Verify private vulnerability reporting/contact before SECURITY
  publishes. Supply macOS/GNOME/KDE/X11 and both Flatpak-host sessions; missing
  evidence keeps M7 open (G16/G17/G23/G24).
